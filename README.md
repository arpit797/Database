## 🎯 SQL Topics & Concepts Covered

### 1. 🔍 Select & Filtering
- Basic `SELECT`, `WHERE`, `DISTINCT`, `IN`, `BETWEEN`, `LIKE`
- Handling `NULL` values (`IS NULL`, `IS NOT NULL`, `COALESCE`, `IFNULL`)

### 2. 🔗 Joins & Unions
- `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `CROSS JOIN`
- `SELF JOIN` (e.g., Employees Earning More Than Their Managers)
- `UNION` & `UNION ALL`

### 3. 📊 Aggregations & Grouping
- `GROUP BY` and `HAVING` clauses
- Aggregate Functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`

### 4. 🪟 Advanced SQL & Window Functions
- Ranking: `DENSE_RANK()`, `RANK()`, `ROW_NUMBER()`
- Analytics: `LEAD()`, `LAG()`, `FIRST_VALUE()`, `LAST_VALUE()`
- Partitioning: `OVER (PARTITION BY ... ORDER BY ...)`

### 5. 🧱 Subqueries & CTEs (Common Table Expressions)
- Scalar and Correlated Subqueries
- `WITH` clauses / CTEs for modular query design
- `EXISTS` and `NOT EXISTS`

### 6. 📅 Date, Time & String Functions
- Date manipulation: `DATEDIFF()`, `DATE_ADD()`, `DATE_SUB()`, `EXTRACT()`
- String manipulation: `CONCAT()`, `SUBSTRING()`, `LENGTH()`, `UPPER()`, `LOWER()`, Regex matching
